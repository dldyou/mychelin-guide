## Quick Start

### Prerequisites

- Node.js 24 LTS
- npm
- Eclipse Temurin JDK 25
- Git

#### Check Versions

```bash
node -v
npm -v
java -version
git --version
```

### 1. Clone the repository

```bash
git clone https://github.com/dldyou/mychelin-guide.git
cd mychelin-guide
```

### 2. Start mobile app

```bash
npm install
npm start
```
